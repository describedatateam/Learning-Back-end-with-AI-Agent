# نسّق شريط تنقل باستخدام Flexbox

في أعلى كل موقع تقريباً شريط: شعار في جهة، وروابط في الجهة الأخرى. **Flexbox** هو أداة CSS لهذا النوع من التنسيق في صف واحد.

## كيف يعمل Flexbox

اكتب `display: flex` على العنصر **الأب**، فيصطف أبناؤه المباشرون في صف. ثم يقرر الأب مكانهم:

| الخاصية | ماذا تفعل |
| --- | --- |
| `justify-content` | توزّع العناصر **على امتداد** الصف: `flex-start` و`center` و`space-between` |
| `align-items` | تصفّ العناصر **عمودياً على** الصف: `flex-start` و`center` و`stretch` |
| `flex-wrap` | القيمة `wrap` تسمح للعناصر بالانتقال إلى السطر التالي عندما لا تتسع |
| `gap` | المسافة بين العناصر |

```css
.toolbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

## مهمتك

في الصفحة شريط `.site-nav` فيه رابط `.logo` وقائمة `.links`. الآن كل شيء فوق بعضه. في الملف `style.css`:

1. اجعل `.site-nav` حاوية Flexbox.
2. أبعد الشعار والروابط إلى طرفين متقابلين.
3. ضعهما في المنتصف عمودياً.
4. اسمح للروابط بالانتقال إلى سطر جديد على الشاشات الضيقة.
5. احذف النقاط من `.links`.
6. اجعل الروابط في صف واحد بينها `16px`.

راقب **المعاينة** وأنت تكتب، ثم اضغط **شغّل الاختبارات**.
