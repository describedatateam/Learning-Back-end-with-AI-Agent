# Day 11: Filtering and search

## Lesson
Understand **Filtering and search** and connect it to the Task Management API. Read the relevant
Django/DRF documentation, then explain the idea in your own words.

## Exercise
1. Inspect the starter code and implement a small example.
2. Add a test or reproducible curl request.
3. Record what changed and why.

## Definition of done
- The example runs with `python manage.py check`.
- A test or request demonstrates expected behavior.
- You can explain one trade-off.

## Stretch goal
Add an edge-case test or a reusable helper.
