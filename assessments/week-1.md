# Week 1 assessment

## Deliverable
Build the week's exercises and demonstrate them with tests or an API walkthrough.

## Definition of done
- [ ] All exercises are complete.
- [ ] `python manage.py check` and `python manage.py test` pass.
- [ ] You can explain the main concept.
- [ ] One edge case and design decision are documented.

## Stretch goals
Add a focused test, improve an error response, or create a reusable abstraction.
