# Final capstone assessment

## Deliverable
Present the Task Management API: users create projects and tasks, filter and paginate lists, and never see another user's data.

## Definition of done
- [ ] Migrations apply from a clean SQLite database.
- [ ] Public health endpoint returns `{"status":"ok"}`.
- [ ] Authenticated project/task CRUD works with validation and ownership isolation.
- [ ] Filtering, search, ordering, pagination, admin, tests, and README are demonstrated.

## Stretch goals
Add token authentication, OpenAPI documentation, CI, or deployment configuration.
Explain how you would monitor and protect production data.
